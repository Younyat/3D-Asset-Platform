Brazo robot industrial

Documentación del rig, articulaciones y animaciones para integración en plataformas 3D

ObjetoIndustrialRobotArm FormatosGLB (animado) · OBJ+MTL (estático) Ejes5 rotativos + 1 pinza Versiónrig 1.0

1. Resumen

Brazo robot industrial articulado, modelado en metros reales y orientado con el eje Y hacia arriba. La cadena cinemática es abierta y serial: base fija → giro de torreta → hombro → codo → muñeca → giro de herramienta → pinza de dos dedos. El movimiento está construido sobre nodos de transformación con nombre, de modo que cualquier plataforma receptora puede animar el brazo de dos formas: reproduciendo los clips incluidos en el archivo, o escribiendo directamente la rotación de cada nodo articulado (control programático o cinemática inversa).

La pinza es siempre el último eslabón de la cadena. Actúa como una mano: dos dedos paralelos que se desplazan de forma simétrica sobre el eje X local para recoger y liberar piezas.

Archivo recomendado para intercambio: brazo-robot-industrial.glb. El GLB contiene la geometría, los materiales PBR, la jerarquía completa de articulaciones, los tres clips de animación y los metadatos del rig (límites, ejes, unidades) en el campo extras del nodo raíz. El OBJ+MTL es únicamente para uso estático: el formato OBJ no soporta jerarquía ni animación.

4.1 Pinza (J6)

Los dos dedos son nodos independientes que se mueven en espejo sobre el eje X local del nodo J5_tool_roll. El valor es la distancia de cada dedo al centro de la herramienta:

6.2 Unity (importación glTF / glb)

  • Importar con glTFast o UnityGLTF; el GLB genera un AnimationClip por cada clip y un GameObject por cada nodo articulado.
  • Escala de importación: 1 (Unity trabaja en metros). Marcar Generate Animation → Legacy/Mecanim según el uso.
  • Para control programático: transform.Find por nombre de nodo y aplicar localRotation = Quaternion.Euler(0, j1, 0). Unity usa mano izquierda, por lo que el signo de los ejes Y puede invertirse; verificar con el clip Demo_Ejes.
  • La pinza se controla con localPosition.x de los dos nodos de dedo, en espejo.

6.3 Unreal Engine

  • Importar el GLB mediante Interchange. Unreal trabaja en centímetros: aplicar escala de importación 100.
  • El rig llega como jerarquía de actores/componentes con nombre; para control en Blueprint usar Set Relative Rotation sobre cada componente articulado.
  • Si se requiere esqueleto, convertir la jerarquía a Skeletal Mesh con un hueso por articulación conservando los nombres de esta tabla.

6.4 Blender / DCC

Importación directa de GLB. Cada articulación aparece como Empty con sus curvas de animación en rotación de cuaternión. Reexportar siempre con +Y up y sin aplicar transformaciones a los nodos articulados, para no romper los ejes de giro.

7. Control programático: reglas de movimiento

  1. Respetar los límites. Escribir valores fuera de rango produce autocolisión visual (el antebrazo atraviesa la torreta). Recortar todo valor entrante contra limitsDeg.
  2. Interpolar, nunca saltar. Los saltos instantáneos de ángulo no son físicamente creíbles. Interpolar hacia el objetivo limitando la velocidad por maxSpeedDegPerSec, con aceleración y desaceleración suaves (perfil trapezoidal o ease-in-out).
  3. Orden de movimiento. En operaciones de recogida, mover primero J1 (orientación), luego J2/J3 (extensión), después J4/J5 (orientación de herramienta) y solo al final J6. La pinza actúa siempre en último lugar, con el brazo detenido.
  4. Mantener la herramienta orientada. Para descender verticalmente sobre una pieza, la suma J2 + J3 + J4 debe mantenerse constante en torno a 180°: eso conserva la pinza apuntando hacia abajo mientras el brazo cambia de altura.
  5. No mover la base. BASE_fixed es estática por diseño; el brazo se traslada moviendo el nodo raíz completo.

7.1 Ejemplo de servo con límite de velocidad

const JOINTS = robot.userData.joints;             // límites del archivo
const target = { J1: 45, J2: 20, J3: 80, J4: 80, J5: 0 };

function step(dt) {
  for (const j of JOINTS) {
    if (j.type !== 'revolute') continue;
    const node = robot.getObjectByName(j.name);
    const cur  = radToDeg(node.rotation[j.axis.toLowerCase()]);
    const goal = clamp(target[j.order], j.limitsDeg[0], j.limitsDeg[1]);
    const max  = j.maxSpeedDegPerSec * dt;
    const next = cur + clamp(goal - cur, -max, max);
    node.rotation[j.axis.toLowerCase()] = degToRad(next);
  }
}

8. Verificación tras importar

  • Los seis nodos articulados existen con su nombre exacto y en el orden de la jerarquía de la sección 3.
  • Los tres clips aparecen con sus duraciones (10,0 / 2,0 / 16,2 s).
  • Demo_Ejes se reproduce completo sin que ningún eslabón atraviese otro: confirma ejes y signos correctos.
  • La pinza abre y cierra de forma simétrica; los dos dedos no se cruzan en el centro.
  • El robot mide ≈ 1,45 m de alto en la pose Home y apoya en y = 0.
  • Cinco materiales PBR con nombre: steel_housing, safety_orange, chrome_joint, cable_rubber, warning_yellow.
